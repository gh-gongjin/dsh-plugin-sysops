如何拿到全盘秒级搜索

Everything 是 voidtools 的 NTFS 索引工具，直接读 USN 日志，所以整个盘几百万文件也只需 84MB 内存和毫秒级查询。本插件不复制它的能力，只把它的结果画成下面的表。
安装（任选一种，由你自己执行——本插件不会替你装程序、不会改注册表、也不会替你打开 HTTP 服务）：
winget install voidtools.Everything
https://www.voidtools.com/downloads/
装好后在 Everything 里勾选 工具 → 选项 → HTTP 服务器（默认端口 3417），或把官方的 es.exe 放进 PATH，然后点上方「重新检测」。
